# docs/archive

Frozen historical documents. Do not modify. Sources:

- Superseded project specifications (before the `obsidian-audit/` pass).
- One-off retrospectives.
- Reference manuals from closed work.

If a file here is still referenced by a live plan, excerpt the relevant part into a new live doc rather than editing this one.

## Layout

Flat files are pre-2026-10-04 material. Anything archived from 2026-10-04 onward
goes in a **dated subdirectory** (`2026-10-04/`) so the consolidation history is legible.

| Entry | Why it is here |
|---|---|
| `2026-10-04/` | The pre-consolidation `CLAUDE.md` state banner (110 lines of resolved history: three archives, four cluster closeouts, the v0.1.0 release note). Its *reasoning* is still the only record of why Reading mode is a `Styled::Editor` leaf and where the Cluster M/O boundary sits. |

## The rule

**These documents have rotted relative links, by design.** They were accurate when
written and their targets have since moved or been deleted. Do not follow links into
this directory for a live task, and **do not fix them** — repairing them would imply the
archives are maintained, and would consume effort better spent on current work.

If a fact you need lives only here, excerpt it into a live document rather than editing
the archived one.
